# গরু বাজার - সম্পূর্ণ প্রোডাকশন ওয়েবসাইট প্যাকেজ

এটি একটি ১০০% সম্পূর্ণ রিয়েক্ট সিঙ্গেল পেজ অ্যাপ্লিকেশন (Full React SPA)। এর মধ্যে রয়েছে:
1. সম্পূর্ণ হোমপেজ ও হিরো ব্যানার
2. সকল গরুর ছবি ও ক্যাটালগ
3. ফিল্টারিং, সার্চ ও লাইভ প্রাইসিং
4. খামারি ড্যাশবোর্ড ও গরু লিস্টিং
5. ক্রেতা ড্যাশবোর্ড ও অর্ডার ট্র্যাকিং
6. অ্যাডমিন সেন্ট্রাল কন্ট্রোল প্যানেল
7. নিরাপদ অ্যাডভান্স পেমেন্ট এসক্রো সিস্টেম
8. খামারি সাবস্ক্রিপশন প্যাকেজ

---

## 🚀 Netlify-তে কীভাবে লাইভ করবেন (১ মিনিট সময়):
১. ব্রাউজারে যান: https://app.netlify.com/drop
২. আপনার কম্পিউটারে এই ZIP ফাইলটি আনজিপ (Extract) করুন।
৩. আনজিপ হওয়া ফোল্ডারটি (যার মধ্যে index.html, assets ও images ফোল্ডার আছে) সরাসরি ব্রাউজারে ড্র্যাগ করে ছেড়ে দিন।
৪. কয়েক সেকেন্ডেই আপনার পুরো ওয়েবসাইট ইন্টারনেটে লাইভ হয়ে যাবে!
